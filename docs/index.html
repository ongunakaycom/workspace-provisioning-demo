💻 Production Execution (CLI)

This demo simulates the planner in your browser. In production, this engine runs as a Python CLI or inside a CI/CD pipeline.

# 1. Safe Dry-Run (0 API calls, prints the diff)
$ python -m provisioner.cli --input data/new_hires.example.csv \
    --snapshot data/snapshot.example.json

# 2. Apply (Executes against Google Workspace)
$ python -m provisioner.cli --input data/new_hires.example.csv \
    --snapshot data/snapshot.example.json --apply

Why dry-run first? In a fintech environment, you never mutate state without reviewing the blast radius. The --apply flag is the explicit human gate.
